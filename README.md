# Product Inventory Management API

A RESTful API built using **Node.js and Express.js** to manage product inventory. This project supports creating, retrieving, updating, deleting, and filtering product records using an in-memory JavaScript array.

## Project Overview

The Product Inventory Management API provides basic CRUD (Create, Read, Update, Delete) operations for managing product records.

Each product contains:
- Unique Product ID
- Product Name
- Category
- Price
- Quantity
- Stock Availability

## Technologies Used

- **Node.js** – JavaScript runtime environment
- **Express.js** – Web framework for building REST APIs
- **JavaScript** – Programming language
- **Thunder Client / Postman** – API testing tools
